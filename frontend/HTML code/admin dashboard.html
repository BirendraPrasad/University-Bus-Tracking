GPS freshness rules

  • LiveLast update 60 seconds ago or less.
  • StaleLast update between 60 seconds and 5 minutes ago.
  • OfflineNo update for over 5 minutes, or no GPS record at all. Never shown as live.

Thresholds will be configurable. Time is based on when the row was stored.
